## 🎮 遊戲核心玩法

這不是一款普通的防守遊戲，而是一場考驗手速與節奏感的**強制理髮直播秀**！
* **精準拍點剃頭**：長髮殭屍會隨著 120~140 BPM 的強烈合成音樂逼近，抓準金色判定圈瞬間點擊左右鍵，一刀將其剃成油光發亮的光頭同伴！
* **豐富怪客機制**：
  * **一般長髮怪**：單擊乾淨剃平。
  * **龐克巨漢 (Hold Note)**：需短按 0.25 拍蓄力，電推滋滋聲響後完美收尾。
  * **戴假髮偽裝怪**：需連續雙擊（第 1 刀挑飛假髮，第 2 刀徹底剃光）。
  * **臥底光頭同伴**：千萬別砍他！放行讓其平安走過可**立即恢復 +20 名譽值 (HP)**。
* **全螢幕拋光大絕 (SPACE)**：累積滿能量後釋放，全場瞬間發出閃耀雷射，將所有殭屍強制同化！

## 📸 獨家特色：免去背自訂光頭頭像

* **隨便選照片就可玩**：點擊「📷 自訂頭像」上傳任意生活照或大頭貼，系統內建橢圓導引框與縮放功能。
* **自動羽化與快取**：自動進行邊緣羽化融合與圓弧裁切，並透過 `localStorage` 本機快取，隨開即用！
* **預設大頭貼**：若未上傳，遊戲會自動讀取同資料夾中的 `player_head.png` 作為招牌主角。
